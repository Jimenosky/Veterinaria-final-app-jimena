==============================================
🆘 SOLUCIÓN DE PROBLEMAS
==============================================

Error: "Cannot connect to localhost:3001"
  → El backend no está corriendo
  → Inicia el backend primero

Error: "Network request failed"
  → Verifica que el backend responda:
    curl http://localhost:3001/api/v1/health
  → Revisa el .env de la app:
    EXPO_PUBLIC_API_URL=http://localhost:3001

Error: Expo no inicia
  → Verifica Node.js: node --version
  → Reinstala: npm install
  → Limpia caché: npx expo start -c

Error: "Module not found"
  → cd a la carpeta del error
  → npm install

Backend no conecta a la base de datos:
  → Verifica DATABASE_URL en .env
  → Verifica conexión a internet (usa Neon en la nube)

==============================================
💡 TIPS IMPORTANTES
==============================================

• Siempre inicia el BACKEND PRIMERO
• Espera 10-30 segundos a que el backend inicie
• Para detener: Ctrl+C en cada terminal
• Para limpiar puerto ocupado:
  netstat -ano | findstr :3001
  taskkill /PID [número] /F

• Los cambios en .env requieren reiniciar
• Usa 'r' en Expo para recargar la app
• Usa Ctrl+C dos veces para salir de Expo
